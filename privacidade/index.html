Privacidade e termos de uso

Como este site trata dados pessoais, segurança e direitos autorais. Versão curta: nenhum dado seu é coletado.

01Quem é o responsável

Este site pertence a Arthur Borges dos Santos, que é o responsável pelo seu conteúdo e pelo tratamento de dados descrito aqui. Para qualquer dúvida, escreva para arthurborgess21@gmail.com.

02Dados que o site coleta

Nenhum. O site é estático: não tem login, banco de dados, cookies de rastreamento, ferramentas de análise de visitas nem anúncios.

03Formulário de contato

Ao enviar o formulário, o seu próprio aplicativo de e-mail é aberto com a mensagem preenchida. Nada é enviado nem guardado por este site; a mensagem só sai quando você a envia pelo seu e-mail.

04Preferências salvas no seu navegador

As escolhas do painel de acessibilidade ficam guardadas apenas no seu navegador (armazenamento local), para que você não precise configurá-las de novo. A demonstração do NEXUS também guarda no seu navegador os dados fictícios que você alterar, o idioma e as preferências de acessibilidade. Nada disso é enviado para mim. Para apagar, basta limpar os dados do site nas configurações do navegador.

05Serviços de terceiros

O site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso, como o endereço IP, conforme a política de privacidade do GitHub. As fontes são carregadas do Google Fonts, o que faz o seu navegador se conectar aos servidores do Google. O tradutor de Libras (VLibras, do Governo Federal) só é carregado se você ativá-lo. Os links para LinkedIn e GitHub levam a sites com políticas próprias.

06Seus direitos (LGPD)

Como o site não armazena dados pessoais, não há cadastro a consultar, corrigir ou excluir. Se você me enviar um e-mail, ele fica apenas na minha caixa de entrada e pode ser apagado a seu pedido.

O código, o design, os textos, as imagens, o vídeo, o currículo e os projetos apresentados aqui, incluindo o NEXUS, estão públicos para consulta e avaliação profissional. Não é permitido copiar, reproduzir, modificar, redistribuir ou usar esse material, inclusive comercialmente, sem autorização prévia por escrito. Fontes, ícones e o VLibras seguem as licenças dos seus autores, e marcas citadas pertencem aos seus donos.

08Segurança

Por ser estático, o site não guarda senhas nem dados de visitantes. Ele usa conexão segura (HTTPS) e uma política de segurança de conteúdo que só permite carregar recursos de origens confiáveis. Se você encontrar uma falha, escreva para o e-mail acima; o contato também está em security.txt.
